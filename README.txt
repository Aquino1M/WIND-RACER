WAVE RACER - JOGO LOCAL

Abra o arquivo ABRIR_JOGO.bat para jogar.

CONTROLES
W / seta para cima: acelerar
S / seta para baixo: frear / re
A D / setas: virar
Espaco: usar uma das 3 cargas de turbo
ESC: pausar

Colete moedas durante a corrida. Use a Garagem e Loja para comprar e selecionar barcos a vela.

MULTIPLAYER ONLINE
Selecione MULTIPLAYER, escolha um nickname e crie uma sala.
Envie o código para os amigos. O anfitrião inicia a corrida.
O progresso é salvo no navegador com um ID exclusivo do jogador.

O jogo possui gráficos 3D com câmera em terceira pessoa e funciona em qualquer navegador moderno.

RECURSOS
- Motor gráfico Three.js atualizado
- Gráficos Leve, Médio e Alto
- Som procedural de motor com variação de aceleração e turbo
- Colisão com barcos, boias e portais
- Vácuo de vento ao navegar atrás de outro barco
- Checkpoints obrigatórios em ordem
- Regeneração lenta de turbo para todos os barcos
- Baleeira Amazônica, Caravela Portuguesa e Drakkar Viking
- Modelos diferentes, skins de casco e velas compráveis
- Prévia 3D giratória na Garagem
